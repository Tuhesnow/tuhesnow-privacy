## 2. Data Stored by TUHESNOW

TUHESNOW may store data created by the user, including:

- tasks and to-do items
- goals and daily goals
- events and calendar-related entries
- notes and productivity data
- app settings and preferences
- progress and completion information

This data is primarily stored on the user’s device.

## 3. iCloud / CloudKit

If the user enables iCloud synchronization, selected TUHESNOW data may be synchronized through Apple iCloud / CloudKit.

The user can choose whether to use supported synchronization features.

## 4. Apple Calendar Integration

Access to Apple Calendar is optional and disabled by default.

TUHESNOW requests calendar access only after the user explicitly enables the calendar integration.

The user chooses which eligible calendars may be imported. TUHESNOW does not automatically import calendar data without user action.

If the user disables the calendar integration, calendar data previously imported by TUHESNOW may be removed from TUHESNOW.

## 5. Backups and Data Export

TUHESNOW may allow users to create backups or export selected categories of their data.

Exported files are created only when requested by the user. Users are responsible for securely storing and sharing exported files.

## 6. Purchases and Subscriptions

Subscriptions and purchases are processed through Apple’s App Store and StoreKit.

TUHESNOW does not receive or store the user’s payment-card details.

## 7. Third Parties

TUHESNOW uses Apple platform services where necessary, including services such as iCloud / CloudKit, StoreKit, and Apple Calendar when enabled by the user.

TUHESNOW does not sell personal data to advertisers.

## 8. Data Deletion
